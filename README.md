A modern, vibrant, and fully responsive landing page for a premium online cookie bakery. The website features an elegant design, a dynamic product catalog, and an engaging user interface designed to showcase premium baked goods.

## ✨ Features

- **Stunning UI/UX:** Bright, modern aesthetic with a rich purple background and high-quality floating visual assets.
- **Product Catalog:** A structured grid showcasing various cookie flavors (e.g., "Best Friends", "Chocolate Frenchman", "Oatmeal with Raisins") with pricing, descriptions, and interactive "Order" buttons.
- **Storytelling Section:** An "About Us" block highlighting the bakery's heritage (crafting handmade cookies since 1995).
- **Navigation:** Smooth scrolling navigation links (Catalog, About Us, Place an Order).

## 🛠️ Tech Stack

- **HTML5:** Semantic markup for structure and SEO friendliness.
- **CSS3:** Custom layouts, modern typography, responsive design elements, and interactive hover effects.
- **JavaScript:** Client-side interactivity and potential order processing logic.

## 📁 Repository Structure

```text
├── .idea/             # Editor configuration files
├── fonts/             # Custom typography assets
├── images/            # High-resolution cookie graphics and backgrounds
├── scripts/           # JavaScript functionality files
├── styles/            # CSS stylesheets for layout and design
├── .gitignore         # System file exclusions (e.g., .DS_Store)
└── index.html         # Main website entry point
```

## 🚀 How to Run the Project

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd bonus-cookies
   ```
3. **Open the project:**
   Simply double-click the `index.html` file to open it in any modern web browser, or use the **Live Server** extension in Visual Studio Code for real-time development preview.
